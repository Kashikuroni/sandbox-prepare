# Реализация согласованной архитектуры

Основные решения: [ARCHITECTURE.md](ARCHITECTURE.md).

## Состояние этапов

- [x] Roadmap универсальных профилей БД и бекапов; PostgreSQL отложен.
- [x] Отделение общих типов и передача конфигурации логирования при запуске.
- [x] Механический перенос существующих функций в Cargo workspace.
- [x] Общий runtime, владение сервисами и регистрация фоновых операций.
- [x] Версионируемая миграция проектов/песочниц без перемещения старых ресурсов.
- [x] Несколько песочниц, адресные операции, очередь двух восстановлений.
- [x] Кеш бекапов проекта с совместными read leases и отменяемой публикацией.
- [x] Локальный Git и клонирование, три режима исходного кода.
- [x] Обнаружение Compose, profiles/overrides, привязки БД и изоляция ресурсов.
- [x] UI выбора/создания проектов и песочниц, настройки и Processes по контексту.
- [x] Общее завершение, Docker events, аварийная сверка и watchdog.
- [x] Проверки полного цикла, обновление документации, очистка тестовых ресурсов.

## Проверки

Из корня репозитория:

```sh
cargo fmt --all --check
python3 scripts/check_architecture.py
cargo clippy --workspace --all-targets --offline -- -D warnings
cargo test --workspace --offline
cargo build --offline
```

Docker-интеграции выполняются явно после сборки основного бинарника.
Каждая проверка использует собственные временные данные и Docker-ресурсы.
Коммиты содержат только title; push выполняется только по явной просьбе.

## Результаты проверки реализации

- Workspace-тесты: миграция, параллельные обращения к единому SQLite-соединению,
  read leases, публикация бекапов, отмена/завершение работников и групп процессов,
  общий лимит Process logs, Git/worktree и существующие функции.
- Через Docker Compose CLI проверено повторное чтение защищённого плана, сохранение
  `$` в значениях, замена БД, зависимости, localhost-порты и изоляция bind mounts.
- Docker: физическое восстановление обеих БД, перезапуск и сохранение старого
  поколения при повреждённом архиве; две параллельные песочницы с проектными
  сервисами; адресная остановка; общий shutdown и изоляция watchdog по сессии.
- Native UI: создание локального проекта и current-checkout песочницы, GPUI-меню,
  обнаружение и анализ Compose. Независимое ревью проверило исправления хранения
  черновиков, изоляции полей, прокрутки селекторов и локальной валидации по исходникам.
- [ ] Повторный визуальный снимок после этих UI-исправлений: CUA возвращал таймауты,
  включая повторное подключение после сброса. Тестовая сборка закрыта. Это ограничение
  визуальной проверки, не подтверждение финального внешнего вида.

Универсальные профили восстановления, PostgreSQL, метрики и HTTP-прокси остаются
в Roadmap. Полное восстановление пользовательских production-архивов не запускалось:
Docker-проверки создавали небольшие собственные физические бекапы.
